# CINEMA GUIDE

## プロジェクト概要
`CINEMA GUIDE` は、映画好きが「お、かっこいい」と感じることを目指した、シネマティックな映画紹介サイトです。  
参考にしているのは「探しやすい情報設計」であり、見た目や演出はオリジナルで設計しています。

現在のサンプル版では、`ショーシャンクの空に`、`インターステラー`、`ラ・ラ・ランド`、`千と千尋の神隠し` など、実在映画をベースに内容を構成しています。

このサイトでは、以下の体験を重視しています。

- ヒーローセクションで世界観に一気に引き込む
- 目次のようにジャンルから探しやすい
- ランキングとジャンル別紹介で比較しやすい
- 気分から映画を選べる

## ファイル構成

- `index.html`
  サイト全体のHTML構造です。ヘッダー、ヒーロー、ランキング、ジャンル一覧、気分検索、CTA、フッターを定義しています。
- `style.css`
  サイト全体のデザインを管理しています。配色、余白、カードデザイン、アニメーション、レスポンシブ対応を含みます。
- `script.js`
  映画データの管理と、画面への描画、ハンバーガーメニュー、スムーズスクロール、気分切り替えなどの動きを実装しています。
- `README.md`
  このプロジェクトの説明書です。
- `assets/`
  画像、背景素材、アイコン、今後追加したいメディアを置くためのフォルダです。初回コミットしやすいように空フォルダ前提で用意しています。

### 推奨ディレクトリ構成

```text
project-root/
├─ index.html
├─ style.css
├─ script.js
├─ README.md
└─ assets/
   └─ .gitkeep
```

## 使い方

1. ルートに `index.html` `style.css` `script.js` `README.md` を置きます。
2. 同じ階層に `assets` フォルダを置きます。
3. `index.html` をブラウザで開きます。
4. そのままでサイトを閲覧できます。

ローカル環境で確認するだけなら、特別なライブラリやビルド作業は不要です。

## カスタマイズ方法

### 映画データの追加方法

映画データは `script.js` の先頭にある `movies` 配列に入っています。  
1作品ごとに、以下のようなオブジェクトを追加してください。

```js
{
  id: 19,
  title: "新しい映画タイトル",
  year: 2026,
  genre: "SF",
  director: "監督: 例 山田",
  catch: "一言キャッチコピー",
  description: "短いあらすじ",
  point: "おすすめポイント",
  tags: ["映像美", "初心者向け", "没入感"],
  rating: 4.7,
  rank: 0,
  moods: ["不思議な世界に入りたい"],
  palette: "linear-gradient(135deg, rgba(100, 120, 255, 0.3), rgba(10, 12, 24, 0.9))"
}
```

補足:

- `rank` を `1` から `6` の数字にすると、ランキング欄に表示されます
- `rank: 0` の場合はランキングに出ません
- `moods` は「気分で探す」欄で使われます
- `palette` はカード上部の背景グラデーションです

### ジャンル追加方法

ジャンルを増やしたい場合は、`script.js` の次の2か所を編集します。

1. `genreMeta`
   ジャンル名ごとの説明文や背景情報を追加します
2. `genreOrder`
   表示順にジャンル名を追加します

あわせて、`movies` 配列の各映画データにも新しいジャンル名を設定してください。

### ヒーロー文言変更箇所

ヒーローの文言は `index.html` の以下の部分で変更できます。

- メインコピー: `.hero-title`
- サブコピー: `.hero-description`
- 小見出し: `.hero-kicker`

CTAボタンの文言も `index.html` 内の `.hero-actions` で変更できます。

### assetsフォルダの使い方

将来的に画像を追加したい場合は、`assets` フォルダにまとめて入れるのがおすすめです。

例:

- `assets/hero-bg.jpg`
- `assets/posters/`
- `assets/icons/`

この構成にしておくと、Gitで管理するときも「素材は assets に集約」と分かりやすくなります。

## デザインコンセプト

今回のデザインテーマは、**「映画館の暗転直後」**をベースにした、よりラグジュアリーなエディトリアルUIです。

- ベースカラーは黒、チャコール、深いネイビー
- アクセントにゴールドと控えめなレッドを使用
- 映画ポスターのような重厚感と、ストリーミングUIの見やすさを両立
- ゴールドの細いラインやフレーム感で高級感を補強
- 装飾を増やしすぎず、余白と明暗差で品よく見せる
- セクションごとに空気感が少し変わるよう、背景グラデーションを調整
- 画像がなくても成立するよう、タイポグラフィとカード設計で魅せる構成

テンプレートっぽく見えないように、ヒーローでは光、オーバーレイ、フィルム感、余白の取り方を使って、緊張感のある第一印象を作っています。

## JavaScriptで実装している機能一覧

- ハンバーガーメニューの開閉
- ナビゲーションリンクのスムーズスクロール
- スクロール時のヘッダー背景変化
- ヒーロー内テキストのフェード表示
- 映画ランキングの動的描画
- ジャンル一覧チップの動的描画
- ジャンル別映画カードの動的描画
- 「気分で探す」ボタンによるおすすめ映画の切り替え

## 編集しやすくするためのポイント

- 映画データは `script.js` にまとめてあるため、追加や差し替えがしやすいです
- HTMLはセクション単位でコメントを入れているため、構造を追いやすいです
- CSSは共通パーツ、カード、ヒーロー、レスポンシブの流れで整理しています

初心者の方は、まず `script.js` の映画データを入れ替えるところから触るとカスタマイズしやすいです。
